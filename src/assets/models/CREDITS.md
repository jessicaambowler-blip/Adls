# Furniture models

The realistic furniture models in this folder come from the **Amazon Berkeley Objects (ABO)**
dataset — credit for the data and 3D models: **Amazon.com**.
Licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/);
dataset: https://amazon-berkeley-objects.s3.amazonaws.com/index.html

Changes made: textures reduced to 512 px (WebP), meshes compressed (meshopt), the recliner
simplified; models are scaled to each item's size in the app.
