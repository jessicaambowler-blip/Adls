Sample floors from **MLSTRUCT-FP** (Pizarro et al., 2023, *Automation in Construction*,
https://doi.org/10.1016/j.autcon.2023.105132), copied from the test data of
https://github.com/MLSTRUCT/MLSTRUCT-FP under the MIT licence (see `LICENSE`).
`fp.json` holds the ground-truth wall rectangles (metres) and each image's scale (pixels per metre).
Used only to score the wall detector (`npm run bench`).
